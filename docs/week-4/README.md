## Three independent3–5minute choices

**Return-path investigator:** trace an anchor and literal return inside actual revised
musical maps, then Compare with matching paths for that same musical section in the
before-map. Numbered positions/intervening section counts explain delayed, shortened
or additional returns. This is relational timeline mapping, not Week2's select-all-map
comparison or Week3's ABA building. It reuses actual Form musical notes/renderer,
including variation counterexamples, accepts every documented valid connection and
makes before/revised comparison operational. Mirrored cases are material variants,
not claimed as different mechanics. Adjacent repetition is outside this brief.

**Dynamics storyboard:** eight expressive contexts provide complete original models
for every segment. Edit p/mf/f start/end and optional first-attack accent; derived
constant/crescendo/decrescendo descriptions explain the actual plan. Accent means
local emphasis of the first attack, not a whole-section loudness instruction or a
changed-last-note accent. All coherent plans can be saved, including alternatives
to the models. No emotional answer key, aesthetic score, sound-level measurement or
claim that dynamics alone communicates a universal feeling. Actual musical sections
and pitch text remain visible; models are suggestions to compare/revise.

**Rhythm tile constructor:** use variable-duration note/rest tiles, insertion positions,
reordering/removal/Undo and remaining-beat budget to make one4/4bar. A half note is
one sustained attack, not two repeated notes. Eight objective briefs constrain space,
duration, attacks, offbeat entry or repeated half-bar. All valid constructions are
accepted. Separate ungraded Free mode accepts all2828supported bars, including silence.
This extends Week1's binary attack/rest workshop by composing duration and onset,
not repeating its grid under a new label. Incomplete drafts remain editable; overflow
is rejected explicitly rather than silently clipped. No compulsory audio.

Each slot offers an optional short stopping point, four pupil-chosen configurations
for activity-specific support/agency, clear objective-versus-ungraded language,
keyboard/touch/focus/48pxcontrols and equivalent text. NN/NB/EN is authored together.
No timer, tour, week lock, compulsory sequence, auto-level change or new admin work.
Visual/text choices do not establish hearing, expressive performance or transfer.

## Musical verification scope

Exact Form material remains A/Av/B/Bv; storyboard X/Y use the existing reviewed
X=D4 E4 G4 A4 and Y=A4 G4 E4 D4, each four quarter notes. Each return pair is a
nonadjacent literal repeat with an intervening different event sequence; same-family
variation is not exact return. All selected pairs and matching before paths are finite.

Story direction derives solely from endpoints, preventing a contradictory arrow and
caption. p=soft, mf=moderately loud, f=loud; crescendo/decrescendo are gradual changes,
not fixed decibels or an emotion. Both complete authored plans in each case remain
examples, not correct answers. Every segment's accent role is explicit.

Tiles use integer half-beat ticks: q/r=2, e/er=1, h/hr=4, target8. The complete6tile
exact8tick domain has2828bars; independent recursion corrected the original mistaken
