## Architecture

Build reusable classify/select-all, slots/sequence, repair, layer, compare, scenario, and compose/snapshot/revise engines. Separate cards, music event data, valid-answer predicates, human-readable feedback, locale strings, level options and saved work. All four levels only where musical distinction is defensible. Objective tasks need independently enumerated valid answers and distractors; creative outcomes never receive aesthetic grades. Use original diagrams and rights-cleared media; instrument range and cultural examples need appropriate human review.

## Production-cost assumptions

Low: text scenario, symbol classification, existing Form mechanics. Medium: notation construction, multi-answer logic, cross-locale feedback. High: ensemble layers, instrument-specific ranges, new audio systems, licensed cultural material. Initially curate 8–16 validated structural cases per configuration and 6–10 creative briefs per mechanic, then observe repetition and adjust. These counts are **planning guesses**. Content IDs and review provenance must be versioned, with no fake uniqueness from transposition alone.
