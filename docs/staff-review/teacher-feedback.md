# Kort lærarguide — privat test av heile Musikkverkstad

**Berre tilsette · ikkje til elevar · alle observasjonar PENDING.** Ingen
lærarrespons er registrert. Bruk berre testval, aldri elevnamn eller elevdata.
Opne den avtalte Teams-lenkja i vanleg nettlesar. Vel Nynorsk, Bokmål eller English.
Lyd: start lågt, trykk spel sjølv. Stopp dersom opning eller lyd ikkje fungerer;
kontakt avtalt intern person. Du skal ikkje installere eller endre nettlesarvern.

Vel **éi** oppgåve i om lag 3–5 minutt. Du treng ikkje prøve heile appen eller alle
seks vekene. Tida er eit framlegg, ikkje ei målt læringseffekt eller ei plikt.

| Valfri inngang | Éin konkret stopp |
|---|---|
| Tema02 → Finn grooven → Lytt → nivå1 | Høyr referanse, A og B ferdig, vel same rytme, samanlikn éin gong. Ingen opptakt. |
| Veke5 → Finn tonen i notesystemet → kort lærarval | Plasser C4/G4 med referansekartet; samanlikn og stopp. |
| Veke6 → Formarrangøren → kort lærarval → opne oppdraget | Bygg A–A′: behald første tre tonar, endre siste. Ved berre Form2: uttrykkeleg ABA/BAB-retur i staden. |
| Veke6 → Tolkingsverkstaden → kort lærarval | Samanlikn modellane med lik dynamikk, vel føremål, endre éin samanheng og stopp. Dette er ein visuell plan utan lyd og estetisk fasit. |

Alle inngangar avheng av skulen sine tillatne aktivitetar/nivå. Prøv gjerne ei anna
oppgåve som er relevant for instrumentet ditt. Ingen fast rekkjefølgje, heile-veker-
krav eller automatisk nivåflytting. Appøving er ikkje prova instrumentmeistring.

## Til den som samlar inn tilbakemelding

Bruk formelle TA1–TA5-kriterium i kjelderepoet (`docs/curriculum/quality-review.md`)
og blank vurderingsprotokoll; denne korte guiden endrar ikkje vedtakskrava. Dette er ein
kjeldereferanse; dei fem kriteria og avgjerdsregelen er oppsummerte her.
Registrer avgrensa brukssituasjon, innvending, ansvarleg og konkret ny prøve. Uklart
føremål, manglande verdi, tung tilråding, tillitsproblem eller uløyste vilkår gir
REVISE/HOLD, ikkje eit positivt gjennomsnitt. Maks to reparasjons-/vurderingsrundar.
TA1–TA5 PENDING til faktiske svar finst; eventuell avgrensa adoption-PASS er ikkje
løyve til elevpublisering eller dokumentasjon på læringseffekt. Musikk, omsetjing,
elev, AT og fysisk lyd/eining er eigne PENDING-sjekkar. Ingen invitasjon er sendt.
