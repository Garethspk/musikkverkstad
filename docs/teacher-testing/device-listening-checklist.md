# Faktisk opning og lyttesjekk — tomt skjema

**PENDING – ingen fysisk opnings-/lyttesjekk er utført av utviklingsagenten.** Éi utfylling per faktisk maskin/nettlesar/lydutgang. Automatiske nettlesarprøver fyller ikkje dette skjemaet.

| Identitet / ramme | Faktisk opplysning |
| --- | --- |
| Dato og ansvarleg kontaktperson/kode | Ikkje registrert |
| PR/commit og HTML artifactSha256 | Ikkje registrert |
| Vist sourceHash/templateHash/candidateHash | Ikkje registrert |
| Maskin/operativsystem/nettlesar og versjon | Ikkje registrert |
| Lokal fil eller annan demonstrasjonsmåte / privat overføringsveg | Ikkje prøvd |
| Høgtalarar eller hovudtelefonar / faktisk lydutgang | Ikkje prøvd |

- [ ] Opna den førebudde HTML-fila frå den private overføringsvegen utan innlogging, installasjon, manuell konfigurering eller endra tryggleiksreglar. Noter eventuell hjelp, filassosiasjon, varsel eller sperring.
- [ ] «Opne øvinga» viser Finn grooven → Lytt → nivå 1; vaksen-/prototypemerking er tydeleg.
- [ ] På eit behageleg volum: førebiletet, A og B gir faktisk høyrbar pianolyd og stillheit der det skal vere pause. Noter rytmemønstra som faktisk blei viste/prøvde; ikkje gå ut frå at A eller B alltid er rett.
- [ ] Ingen høyrd ekstra teljing før rytmen; dei fire cellene kan samanliknast. Eit val som er ulikt, blir ikkje godteke som likt etter at alle tre er høyrde ferdig.
- [ ] Stopp bryt lyden; avslutting under avspeling eller lasting etterlet ikkje lyd eller ei gjenopna økt. Ny opning startar ei tom prøveøkt.
- [ ] Normal navigasjon og nivåval fungerer; nettlesarzoom/skjerm gjer kontrollane lesbare og tilgjengelege.
- [ ] Høyrde skilnadar, feil, usikkerheit og behov for hjelp er noterte, utan elevidentitet eller obligatorisk opptak.

| Funn / friksjon | Tiltak og ny faktisk kontroll | Status |
| --- | --- | --- |
| Ingen observasjonar registrerte | — | PENDING |

Ikkje set kryss utan faktisk observasjon. Ved sperra lokal fil: hald att dette opningsvilkåret; ikkje bruk ein HTTP-test som prov på lokal opning, eller slå av tryggleiksreglar. Ved fysisk telefon-/nettbretttest: fyll ut eit eige skjema; ei smal nettlesarramme er ikkje ein telefontest. Lyttesjekken er ikkje TA1–TA5-adopsjonsvurdering eller godkjenning for elevpublisering.
