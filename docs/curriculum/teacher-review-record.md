# Lærarvurdering — tomt skjema og gjennomføringsnotat

**Ikkje utfylt · ingen tilrådingar eller godkjenningar registrerte · status PENDING**

Bruk éin kopi per lærar. [Lærararket](teacher-review-pack.md) inneheld den eine øvinga og spørsmåla. Dette dokumentet er eit blankt hjelpemiddel, ikkje dokumentasjon på at nokon har delteke.

## Før gjennomgangen — til den som leier vurderinga

Inviter eit lite, variert utval, til dømes 3–5 instrument-/ensemblelærarar med ulike instrument, erfaringar og teknisk tryggleik. Ta også med skeptiske syn. Talet er eit praktisk framlegg, ikkje ein validert terskel eller eit representativt utval. Denne pakken sender ingen invitasjonar og opprettar ingen kontoar.

Set av om lag 10–15 minutt per lærar, med ei 3–5-minutts øving inni gjennomgangen. Gi ei førebudd utgåve med Tema 02 og nivået tilgjengeleg; læraren skal ikkje måtte konfigurere skulen eller installere verktøy. Oppgi nøyaktig kva utgåve som blir vist og kva som ikkje er prøvd. Be læraren finne og prøve øvinga utan rettleiing først; noter hjelp som faktisk blir gitt. Ikkje krev at læraren prøver med elevar eller gir ei positiv tilråding.

Dersom berre designark blir viste, merk funna som førebels designtilpassing. Enkel tilråding i den ferdige utgåva må prøvast på den utgåva før ein avgrensa adoption-PASS kan vurderast. Privat vaksenvurdering er ikkje løyve til elevpublisering. Musikalsk kvalitet og lærartilpassing skal registrerast kvar for seg, også når same person vurderer begge.

## Éin lærar — faktisk observasjon og svar

| Felt | Fyll inn etter faktisk gjennomgang |
| --- | --- |
| Lærarkode / dato | Ikkje registrert |
| Brei undervisningsramme: instrument, individuelt/ensemble, relevant erfaring | Ikkje registrert; ingen elevidentitet |
| Vist artefakt: fil/versjon/commit, privat prototype eller berre designark | Ikkje registrert |
| Faktisk rute: Tema 02 → Lytt → valt nivå | Ikkje prøvd |
| Kva hjelp måtte givast? Eventuell tids-/navigasjonsbyrde | Ikkje observert |
| TA1: føremål og avgrensingar, med lærarens eigne ord | Ingen svar |
| TA2: konkret verdi i eiga undervisning, alternativ og avgrensingar | Ingen svar |
| TA3: lærarens eiga formulering av éi tilråding; det som var lett/vanskeleg | Ingen svar |
| TA4: tillit, rolle og innvendingar | Ingen svar |
| TA5: frivillig tilråding, nøling/nei/vilkår og anonymisert behov | Ingen svar; inga tilråding innhenta |
| Vurdert bruksramme; kva funna ikkje dekkjer | Ikkje avgrensa |
| Føreslåtte endringar og kva som må prøvast på nytt | Ikkje registrert |

Bruk om mogleg lærarens eigne formuleringar. Skil observasjon frå tolking: «trong hjelp til å finne Lytt» er noko anna enn «ville nok ha funne det». Ikkje fyll manglande svar med modellsvar eller positive døme. Ikkje noter elevnamn, opptak, kontaktopplysningar eller offentlege sitat; avtal lagring og sletting av vurderingsnotat etter lokale rutinar utanfor appen.

## Innvendingar, endringar og avgrensa ny vurdering

| ID / kriterium | Faktisk innvending eller observasjon | Føreslått endring / ansvar | Omfang og status | Ny vurdering, pass 1 eller 2 |
| --- | --- | --- | --- | --- |
| — | Ingen funn registrerte | — | PENDING | Ikkje gjennomført |

Registrer avslag og uløyste innvendingar også når andre lærarar er positive. Ikkje bruk gjennomsnitt eller fleirtal til å skjule eit vesentleg problem. Ved ulik tilpassing til instrument eller undervisningsrammer må påstanden avgrensast; andre rammer blir ståande uavklarte. Maksimalt to endrings-/vurderingsrundar per pulje; hald att det som ikkje blir løyst.

## Samla avgjerd — skal ikkje fyllast ut på førehand

| Avgjerdsfelt | Status no |
| --- | --- |
| Faktisk lærargrunnlag og viste artefaktar | Ingen |
| TA1–TA5: kva har faktisk støtte i svar/observasjon? | Ikkje vurdert |
| Uløyste vesentlege innvendingar / avgrensingar | Ukjende; ingen gjennomgang |
| Lærartilpassing / teacher-adoption/design fit | **PENDING** |
| Ansvarleg avgjerdstakar / dato / avgrensa omfang | Ikkje registrert |
| Neste handling | Innhent faktisk lærarfeedback; ikkje endre status på grunnlag av dette tomme skjemaet |

Utan faktiske svar: PENDING. Ved uklart føremål, manglande verdi, tung tilråding, tillitsproblem eller vilkår som ikkje er løyste: REVISE/HOLD. Ein avgrensa adoption-PASS krev faktisk støtte for alle TA1–TA5 og ingen uløyste vesentlege innvendingar innan det oppgitte omfanget; bruk [den fullstendige avgjerdsregelen](quality-review.md#teacher-adoptiondesign-fit-gate-not-performed). Eit tomt skjema, ei venleg interesseytring eller ein modellgjennomgang kan ikkje gi PASS.

Ei eventuell lærartilpassing-PASS seier ikkje at elevar lærer betre, at musikalsk fasit er rett, at eigaren har godkjent implementering, eller at utgåva kan publiserast til elevar. **Pupil release er framleis BLOCKED; PR #9 skal vere draft.** Ingen aktivitetar, samanslåingar eller utrullingar er del av denne gjennomgangen.
